# 📷 C++ Image Processing Project

This is a beginner-friendly image processing project written in **C++**. It allows loading, manipulating, 
and saving PNG images using a custom `Picture` class and the [LodePNG](https://lodev.org/lodepng/) library for image decoding and encoding.

---

## 🚀 Features

- ✅ Load PNG images
- ✅ Flip image vertically
- ✅ Flip image horizontally
- ✅ Double the size of the image
- ✅ Apply a custom color filter
- ✅ Save the modified image
